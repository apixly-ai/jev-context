# Community code of conduct

Be respectful, constructive and specific. Welcome people with different experience
and backgrounds. Critique code and evidence, not people. Harassment, threats,
discriminatory abuse, unwanted sexual attention and disclosure of private information
are not acceptable.

Maintainers may remove content, close discussions or restrict participation to protect
the community. Use a private security advisory for sensitive reports; for ordinary
moderation concerns, contact the maintainer through an appropriate GitHub channel
without publishing private details. These expectations apply to project issues,
pull requests and discussions.
