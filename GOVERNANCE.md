# Governance and support

JIA-ss is the initial maintainer and release owner. Decisions are documented through
issues, pull requests, changelog entries and benchmark reports. The project is
independent of TypeSafe and browser/model providers.

0.1.x is an early release, not an enterprise SLA. Runtime changes require tests;
semantic changes require scoped evaluation. We prioritize correctness, evidence
retention and reproducibility over claims of universal speedups.

Support channels: GitHub issues for reproducible bugs, Discussions for usage/design,
private vulnerability reporting for security issues. Commercial support, hosted
service availability and guaranteed response times are not offered by this repository.

If additional maintainers join, CODEOWNERS and branch rules will be updated through
a public PR. Breaking changes require a migration note. Security embargo details
remain private until coordinated disclosure.
