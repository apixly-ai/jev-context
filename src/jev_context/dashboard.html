统计口径与计价依据

基线是本次收集到的规范化记录 JSON，比较项是实际返回的完整文本包（包括元数据和换行）。二者仅计算一次，不代表未筛选时主模型一定会读取的内容，也不包括整个对话、工具定义、输出、重读或后续重试。

目标模型取自本地配置，不会自动识别当前 Codex 模型。tiktoken 是选定编码的文本计数；显式指定编码属于代理估算，不保证匹配目标模型。bytes 是 UTF-8 字节数 ÷ 4 向上取整的粗估。官方 API 计数是独立消息包的计数，并非实际 Agent 请求的 usage。各模型 tokenizer 不同，跨模型合计只作用量汇总。

输入价值 = 减少 token × 输入单价；净值 = 输入价值 − Jev 成本。采用调用时保存的 USD/百万 token 单价，不含缓存优惠、税费或订阅套餐。单价由配置者提供，日期不是自动核价证明。

不完整、透传与 typed-batch 调用不计算减少量。typed-batch 返回的判断不是最终主模型消息，没有可靠基线。缺失用量、价格或计数保留未知；净值只有全部行可算时才提供总额。失败或跳过统计前的调用可能未入账。
